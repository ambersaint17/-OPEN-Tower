# Banner images (optional)

Tower ships **without** banners, and works perfectly without them. If you want a banner at the top of a card, put a PNG here with the matching name. Missing files are skipped silently, so add as many or as few as you like.

Recommended size: **1600 x 280 px**.

| File | Where it shows |
| --- | --- |
| `panel-banner.png` | Help, the embed builder, and anything without its own banner |
| `banner-verification.png` | Verification panel |
| `banner-tickets.png` | Ticket panel and ticket cards |
| `banner-moderation.png` | Moderation cards |
| `banner-levels.png` | Levels and perks |
| `banner-boost.png` | Booster thank-you |
| `banner-youtube.png` | YouTube announcements |
| `banner-earlyaccess.png` | `/earlyaccess` posts |
| `banner-qotd.png` | Question of the day |
| `banner-giveaway.png` | Giveaways |
| `banner-commission.png` | Commissions |
| `banner-staff.png` | Staff offers and promotions |
| `banner-partner.png` | Partnership ads |

`partner-mute-guide.png` is a generic "how to mute this channel" picture used by the partnership channel. You can replace it.
Your own banners are ignored by git (see `.gitignore`), so they never end up in a public repository by accident.
